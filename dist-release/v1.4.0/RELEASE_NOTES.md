# Musomo Tracker v1.4.0

## What's new

- **Midnight timer split** — live sessions crossing midnight save as two rows (day 1 closes at 24:00; day 2 continues running or stays paused); reliable even after sleep or background
- **Overnight manual entry** — when end is before start on the same date, two sessions are created automatically
- **Manual time input** — `HH/MM/SS` digit mask with fixed slashes; cleaner modal styling
- **Mini Timer (macOS)** — red closes with save dialog, yellow compact size, green default size; **Don't save** correctly discards the open session
- **Timer reliability** — elapsed time from wall clock; improved sync when returning from background or sleep

## Download

- **macOS (Apple Silicon):** `Musomo Tracker_1.4.0_aarch64.dmg`
- **macOS (Intel):** `Musomo Tracker_1.4.0_x64.dmg`
- **Windows 10/11 (x64):** `Musomo Tracker_1.4.0_x64-setup.exe`

## Install (macOS)

1. Download the DMG
2. Open it and drag **Musomo Tracker** to Applications
3. Launch the app

Signed and notarized for macOS.

## Install (Windows)

1. Download the setup `.exe`
2. Run the installer and follow the prompts
3. Launch **Musomo Tracker** from the Start menu

Unsigned Windows build (SmartScreen may prompt on first run).
