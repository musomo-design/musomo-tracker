# Musomo Tracker v1.3.31

## What's new

- **Manual session entry fixed** — Start/End/Break use 24h `HH:MM:SS`; billable time = (End − Start) − Break
- **Time input** — single field with fixed colons; type digits only (e.g. `083000` → `08:30:00`)
- **Break validation** — break cannot exceed the session window
- **Calculator removed** — simplified manual entry flow

## Download

- **macOS (Apple Silicon):** `Musomo Tracker_1.3.31_aarch64.dmg`
- **macOS (Intel):** `Musomo Tracker_1.3.31_x64.dmg`
- **Windows 10/11 (x64):** `Musomo Tracker_1.3.31_x64-setup.exe`

## Install (macOS)

1. Download the DMG
2. Open it and drag **Musomo Tracker** to Applications
3. Launch the app

Signed and notarized for macOS.

## Install (Windows)

1. Download the setup `.exe`
2. Run the installer and follow the prompts
3. Launch **Musomo Tracker** from the Start menu

Unsigned Windows build (SmartScreen may prompt on first run).
